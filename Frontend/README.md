# Frontend

Regras genéricas para frontends web estão centralizadas em:

```
../.windsurf/rules/
```

Copie pelo menos:

- `frontend-core.md`
- `frontend-state.md`
- `frontend-forms.md`
- `frontend-security.md`
- `security-core.md`
- `commit.md`
- `release.md`

Combine com a regra da stack usada no projeto, por exemplo `nextjs-*`, `vue-*`,
`angular-*` ou `vite-*`.
