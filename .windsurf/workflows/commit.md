# Commit

1. Verifique o branch atual.
2. Valide lint/build/test quando aplicável.
3. Escreva a mensagem seguindo `commit.md`.
4. Execute `git add` e `git commit`.
5. **Não faça push nem merge** sem solicitação explícita do usuário.

```bash
git add .
git commit -m "feat: descrição curta em português"
```
