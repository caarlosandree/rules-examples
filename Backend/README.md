# Backend

Regras genéricas para backends estão centralizadas em:

```
../.windsurf/rules/
```

Copie pelo menos:

- `backend-core.md`
- `backend-api.md`
- `backend-data.md`
- `backend-security.md`
- `backend-observability.md`
- `security-core.md`
- `security-analysis.md` quando houver auditoria
- `postgresql.md`, `mysql.md` ou `mongodb.md` conforme o banco
- `commit.md`
- `release.md`

Combine com a regra da stack usada no projeto, por exemplo `java-*`, `go-*`,
`nestjs-*` ou `python-*`.
