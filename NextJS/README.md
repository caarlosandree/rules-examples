# NextJS

Regras genéricas para projetos NextJS estão centralizadas em:

```
../.windsurf/rules/
```

Copie pelo menos:

- `nextjs-core.md`
- `nextjs-ui.md`
- `nextjs-testing.md`
- `nextjs-checklist.md`
- `security-core.md`
- `commit.md`
- `release.md`

Se o projeto tiver BFF, Route Handlers ou acesso direto a dados, copie também a regra de banco correspondente.
