# Mobile

Regras genéricas para apps mobile estão centralizadas em:

```
../.windsurf/rules/
```

Copie pelo menos:

- `mobile-core.md`
- `mobile-checklist.md`
- `frontend-forms.md` quando o app usar formulários com schema
- `security-core.md`
- `commit.md`
- `release.md`

Antes de aplicar em um projeto real, ajuste biblioteca de UI, navegação, comandos
de lint/typecheck, estratégia de token/storage e fluxo de build/release.
